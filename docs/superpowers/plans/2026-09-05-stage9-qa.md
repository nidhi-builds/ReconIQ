# Stage 9 Text-to-SQL Q&A Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> superpowers:executing-plans to implement this plan task-by-task. Steps use
> checkbox (`- [ ]`) syntax for tracking.

**Goal:** Answer questions over completed reconciliation runs with safe,
evidence-backed SQL and a measured Gemini-to-NVIDIA fallback.

**Architecture:** FastAPI will fetch typed rows from Supabase. The agent builds
a per-question SQLite snapshot, validates and executes one read-only query, and
asks the selected provider to summarize only returned rows.

**Tech Stack:** Python 3.13, Pydantic 2, sqlite3, google-genai, NVIDIA NIM's
OpenAI-compatible HTTPS API, pytest.

**Spec:** `docs/superpowers/specs/2026-09-05-stage9-qa-design.md`

## Global Constraints

- Primary is `gemini-2.5-flash`; the measured fallback candidate is
  `nvidia/nemotron-3.5-lightning-30b-a3b`.
- Temperature is zero; model responses are schema validated.
- Ground truth and secrets never enter prompts or snapshot rows.
- Unsafe or runtime-aborted SQL refuses locally without fallback.
- Do not commit without explicit user approval.
